Implemented
- Mobile nursing record/stop/review/send/discard flow; Malayalam, English, Arabic
  and mixed-speech extraction instructions; optional ward; editable room/department/request.
- Nursing language bar and language setting removed. Transcription automatically
  detects the spoken language; no selected-language hint is sent. Patient language
  controls remain unchanged. Existing nursing language preferences are ignored.
- Browser MediaRecorder with permission handling, 120-second limit, track cleanup,
  6 MiB upload cap, processing indicator, retry and idempotent request submission.
- nursingTranscribe callable authenticates enabled Staff, validates origin/audio,
  requests structured extraction; no request is created until Send.
- New transcription uses configurable NURSING_TRANSCRIPTION_MODEL; default
  gemini-3.8-flash, current Interactions REST API with store:false. No Files API upload or raw
  audio persistence. API docs consulted: https://ai.google.dev/gemini-api/docs/audio
- Staff read own submitted requests plus assigned tablet requests.
- Administrator reads all requests. Department admin reads only its category.
- dashboard.html rejects department-admin and retired non-clinical accounts;
  department admin can open its category dashboard and category-scoped request log.
- Staff/Administrator can use category pages as scoped views.
- Department admins accept; Staff accept Nursing only and complete their visible
  accepted requests. Administrator can accept/complete hospital-wide requests.
- Completion stores employee ID, signed-in UID and server timestamp.
- Seven department slots, transactionally reserved, remain occupied if disabled.
  Duplicate creation is rejected before any Auth account is created. Failed Auth
  creation releases its newly reserved slot. Existing legacy accounts can migrate
  through Master Admin Edit; their UIDs are preserved.
- Non-clinical is no longer a creatable role. Existing users are not deleted.
- New asset list is prepared in the workflow file, not pushed or executed.
